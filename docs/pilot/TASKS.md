# Pilotaufgaben und Ergebnisprotokoll

Alle Aufgaben **nicht ausgeführt**. Auf einer vom Owner freigegebenen Instanz mit
festgehaltenem Build ausführen. Vorbereitung: [Pilotleitfaden](README.md).
Nicht verwendete Funktionen ausdrücklich aus dem Pilotscope nehmen; nicht als
bestanden markieren. Tatsächliche Personen-/Kontaktdaten nicht in Git dokumentieren.
