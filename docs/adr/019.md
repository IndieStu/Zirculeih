# ADR-019 – Isolated owner/team review profile

Date: 2026-10-16. Status: implementation for the explicitly authorized UX gate;
Phase-6 acceptance remains pending.

The owner requires a private NCtest/Tailscale test instance before Phase 7. Extend
existing Compose instead of another deployment architecture. Named review DB/media/
static/mail volumes and a dedicated interpolation environment isolate data and
credentials; only a private address binds the application. Existing PostgreSQL 17
image, container restrictions, readiness and migrations remain authoritative.

Configuration-driven review mode forces local file mail and a visible TESTINSTANZ/
Git build marker, rejects DEBUG and activated OIDC, and serves collected read-only
public static files for direct private access. This is a review deployment choice,
not removal of required staff OIDC support. No private media bypass is introduced.
Existing Caddy can terminate private TLS using its internal CA, without public ACME.

Explicit seed operates only on an empty review database, inside the authorization
transaction, through productive services. Synthetic historical time creates valid
booking/custody evidence. Published fictional agreement versions, fictional identity
checks and profiles are fixture evidence only. A singleton marker records anchor
and role IDs. Repeated invocation preserves team changes; no startup or daily reset.
Passwords are unusable until an explicit operator command, then normally hashed,
validated and session-invalidating. No seed writes run in ordinary production mode.

All UUIDs and generated opaque codes remain real randomly generated identities;
semantic dataset, inventory numbers and anchor-relative states are reproducible.
No deterministic security token generator or alternative booking path is added.
Bundles, qualifications, recurrence and redesign remain outside this gate.

Validation: real PostgreSQL seed/idempotency/permission tests, normal regression,
Docker/Linux/PG17 deployment, browser workflow and mobile checks. Deployment and
review guides document update/reset and database+media restore. No new dependency.
