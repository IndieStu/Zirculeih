# Die wichtigsten Begriffe

**Asset:** ein einzeln inventarisierter physischer Gegenstand, etwa Akku, Tisch, Projektor oder Maschine. Inventarnummer und Standort beschreiben den Inventargegenstand. Ein Asset muss weder verleihbar noch buchbar sein.

**Resource / Angebot:** eine nutzbare oder buchbare Fähigkeit, etwa Raum, Maschine, Fahrzeug oder Geräteangebot. Diese nächste Ausbaustufe kann auf Assets zurückgreifen, muss es aber nicht. Ein Raumangebot ist kein zwingender physischer Inventargegenstand. Eine spätere ResourceUnit bezeichnet eine konkrete zuweisbare Einheit; sie ersetzt das Asset nicht.

**Standort:** ein frei aufgebauter Ort im Baum, zum Beispiel Gebäude → Werkstatt → Schrank. Kategorien ordnen Gegenstände fachlich ein, Standorte sagen, wo sie liegen. Es gibt keine vorgegebenen WERK-Ebenen oder fest eingebauten Kategorien.

**Zustand:** wie der Gegenstand beschaffen ist, etwa gut oder beschädigt. **Lebenszyklus:** seine betriebliche Einordnung, etwa aktiv, Wartung oder ausgemustert. Ein Zustandswechsel ändert nicht automatisch den Lebenszyklus.

**Identifier:** ein Code, der einen konkreten Gegenstand innerhalb eines ausdrücklich gewählten Namensraums erkennt. Mehrere Codes können dasselbe Asset bezeichnen. Ein Barcode für eine Produktserie eignet sich nicht als eindeutige Inventaridentität mehrerer gleicher Gegenstände.

**Gruppe und Recht:** Zugehörigkeit und ausdrückliche Aktionen bestimmen, was du in welchem Bereich tun kannst. Mitarbeitendenstatus oder Systemadministration allein geben keine operativen Inventarrechte. Eine ausdrückliche Verweigerung hat Vorrang.

**Reservierung und Ausleihe:** werden später getrennte Vorgänge. Eine Reservierung betrifft zugesagte Nutzung; eine Ausleihe dokumentiert tatsächliche Ausgabe/Rückgabe. Beides ist noch keine Funktion der Phase-3-Inventaroberfläche.
